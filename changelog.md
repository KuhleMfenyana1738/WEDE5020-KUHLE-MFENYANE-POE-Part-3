## How to run the website

1. Extract the ZIP file.
2. Open the `wede5020-poe-part3` folder in VS Code.
3. Open `index.html` in a browser.
4. Test each navigation link.
5. Open Developer Tools with F12 and use Console to see JavaScript messages.

## What JavaScript is used for

Home:
- main.js controls the active navigation link.

About Us:
- main.js controls the FAQ accordion.

Services:
- search.js filters service cards while the student types.

Gallery:
- lightbox.js opens a larger image and closes it.

Contact Us:
- validation.js checks the name, email, service and message before showing success.
